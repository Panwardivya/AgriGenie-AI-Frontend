 🌾 AgriGenie AI

**Agricultural Intelligence Platform**

AgriGenie AI is a web-based agriculture project designed to provide farmers with useful agricultural information and digital tools through a single platform.

 🚀 Project Modules

- **Dashboard** – Overview of the platform.
- **Crop Advisory** – Agricultural guidance and recommendations.
- **Disease Detection** – Interface for crop leaf disease detection.
- **Weather** – Weather information interface.
- **Market Prices** – Mandi and commodity price interface.
- **Analytics** – Data visualization and analytics.
- **User Profile** – User profile interface.
- **Admin Dashboard** – Administration interface.
- **Voice Assistant** – Voice interaction interface.

 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
